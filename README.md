# Attention-decay in pandemic surveillance is an emerging-disease phenomenon

A multi-signal evaluation of wastewater, search-query, information-seeking, and outpatient-syndromic surveillance signals across COVID-19 (2021–2024) and influenza (2021–2025).

**Submitted to:** AIxBio Hackathon, Apart Research, Track 2 — Pandemic Early Warning, April 2026.
**Author:** Taggart Tufte, Department of Mathematical Sciences, Montana State University.
**Paper:** [`paper/paper.pdf`](paper/paper.pdf) · 8–10 pages · headline figure [`paper/figs/fig3_covid_vs_flu.png`](paper/figs/fig3_covid_vs_flu.png).

---

## TL;DR

Multi-signal surveillance treats additional data sources as additive contributions to detection performance. This study tests that assumption across the multi-year endemic-transition phase of an emerging pathogen (COVID-19) and compares against an established endemic pathogen (influenza). The headline finding is that **attention-based signals (Google Trends, Wikipedia) show 5–23× variance compression after the first major COVID-19 wave but show no compression across flu seasons.** Wastewater surveillance is the only signal type with stable variance across both diseases.

| Signal | COVID-19 (BA.1 vs post) | Influenza (2022–23 vs subsequent) |
|---|---|---|
| **NWSS national wastewater** | **1.59×** | **2.07×** |
| Google Trends (US) | **22.85×** | **0.91×** |
| Wikipedia pageviews | 4.65× | 1.26× |
| HHS hospital admissions | 12.93× | 3.34× |

A ratio near 1 indicates calibration is preserved across the lifecycle. The COVID column is the diagnosis; the flu column is the control. Attention decay is an emerging-disease novelty-cycle phenomenon, not a general property of attention-based surveillance signals.

The paper additionally reports a negative result on LLM-prompt surveillance: WildChat-4.8M (3.2M conversations) yields <0.1% first-person illness reports — too sparse for population-scale surveillance — and discusses what a Microsoft-Copilot-scale privacy-preserving aggregate stream (per Costa-Gomes et al. 2026, *Nature Health*) would resolve.

A Bayesian likelihood-ratio analysis (paper §5.4) sharpens the operational picture: post-emergence, Wikipedia fails **loud** (alerts keep firing but P(wave | alert) collapses 0.83 → 0.43) while Google Trends fails **silent** (alerts nearly stop firing at all — high apparent precision, ~5 alerts in 2 years). Wastewater is the only signal that is neither, holding P(wave | alert) at 0.87 across eras. A dashboard that tracks only per-alert precision will catch the loud failure and miss the silent one.

## Reproduction

### Environment

```bash
python -m venv venv
source venv/Scripts/activate   # bash on Windows
pip install -r requirements.txt
```

PyTorch with CUDA is required for the WildChat classifier pilot (DeBERTa zero-shot). Install separately if you don't have CUDA torch:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu124
```

### Data download

All data sources are public, but two require HuggingFace authentication (see `DATASETS.md`). Quick paths:

```bash
# Public CDC + Delphi data — no auth needed
python notebooks/_pull_wikipedia.py      # ~1 minute
python notebooks/_pull_ilinet.py          # ~10 seconds
python notebooks/_pull_covid_truth.py     # ~30 seconds
python notebooks/_pull_flu.py             # ~1 minute
python notebooks/_pull_trends.py          # ~1-2 minutes (rate-limited)

# NWSS bulk downloads
curl -sL "https://data.cdc.gov/api/views/g653-rqe2/rows.csv?accessType=DOWNLOAD" \
     -o data/raw/nwss_concentration.csv         # 18 MB
curl -sL "https://data.cdc.gov/api/views/2ew6-ywp6/rows.csv?accessType=DOWNLOAD" \
     -o data/raw/nwss_metric.csv                # 125 MB
curl -sL "https://data.cdc.gov/api/views/ymmh-divb/rows.csv?accessType=DOWNLOAD" \
     -o data/raw/nwss_flu_a.csv                 # 120 MB

# WildChat (gated — requires HF token)
echo "hf_your_read_token" > .hf_token
python -m src.hf_download
```

### Run the analyses

```bash
# Build aggregated wastewater indices
python -m src.nwss_aggregate           # COVID, ~30s
python -m src.nwss_flu_aggregate       # flu, ~30s

# Reproduce paper figures (writes to paper/figs/)
python notebooks/07_polish_figures.py

# Reproduce the headline analysis
python notebooks/06_flu_comparison.py

# Reproduce the LLM-prompt pilot (requires GPU + HF token)
python notebooks/02_wildchat_pilot.py
```

## Methods summary

- **NWSS aggregation.** Population-weighted mean of log₁₀-transformed flow-population-normalized concentrations across reporting sites, with per-site daily interpolation (≤14-day gaps) and a minimum-samples filter (100 for COVID, 50 for flu). Replicates CDC's national wastewater dashboard logic.
- **Variance ratio.** For each signal × disease, compute Var(reference window) / Var(subsequent window). Reference: BA.1 era for COVID (2021-12 → 2022-02); 2022–23 season for flu (2022-12 → 2023-02). A ratio near 1 indicates calibration is preserved across the lifecycle.
- **Detector evaluation.** Moving-average control chart (28-day window, 3-day gap) and one-sided CUSUM on log-concentrations. Wave detection events are CDC-narrative-reporting variant peak dates; alert in 60-day pre-peak window counts as a detection. Consecutive alert days are collapsed into single episodes.
- **LLM-prompt classifier.** Two-stage filter: (1) keyword pre-filter on respiratory-symptom vocabulary (~50 terms); (2) DeBERTa-v3-base-mnli-fever-anli zero-shot classification with multi-label scoring on illness, fictional-content, and general-medical labels. Threshold P(illness) ≥ 0.7 ∧ P(fiction) ≤ 0.5.

## What I'd do with more time

Roadmap of natural extensions, in case this evolves beyond the hackathon:

1. **Replicate on a second emerging-pathogen lifecycle.** Mpox 2022 has wastewater coverage and a clear emergence-then-decline pattern. H5N1 in dairy cattle 2024 would test on a non-respiratory pathogen. Both would strengthen the novelty-cycle generalization.
2. **County-level analysis.** Currently NV-state aggregate has only 3 NWSS sites. Pulling Clark County (Las Vegas) wastewater specifically and matching to Clark County hospital admissions would enable a clean local-scale analysis the current state-level work cannot support.
3. **International replication.** All signals are US-centric. European (RIVM, ECDC) data would test whether attention-decay dynamics are culturally specific.
4. **Engage Microsoft / Anthropic / Google on aggregate releases.** The negative result on WildChat motivates a system-design proposal: a privacy-preserving weekly aggregate (state, week, count of first-person respiratory-illness conversations) released by major LLM providers. This is the natural next step from the analysis.
